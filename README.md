# Assignment-2
## Program 1: Even or Odd Number Checker
**Functionality:**
- Prompts the user to enter an integer.
- Checks whether the entered num is **even** or **odd** using an `if-else` condition.
- Displays the result to the user.
  
## Program 2: Sum of Numbers from 1 to 50
**Functionality:**
- Uses a `for` loop to iterate through numbers from **1 to 50**.
- Calculates the sum of these numbers.
- Displays the result to the user.
